MegaZIP 023 — JVM por módulo

El log Pasted text(87).txt confirma que los errores anteriores de:
- assets_audio_player requestedPermissions nullable
- audio_session Kotlin 11 contra Java 17

ya desaparecieron.

El nuevo bloqueo es:
:file_picker:compileDebugKotlin
Java target = 11
Kotlin target = 17

Causa:
MegaZIP 022 forzó JVM 17 globalmente para todos los módulos Kotlin Android.

Corrección:
- JVM 17 únicamente para:
  app
  assets_audio_player
  audio_session

- JVM 11 para:
  file_picker
  demás plugins Android heredados

No modifica código Dart, diseño, pagos ni funcionalidad.

Aplicación:
1. Descomprimir en F:\SALUMED\CODE\APP
2. Ejecutar:

Set-ExecutionPolicy -Scope Process Bypass
.\CORREGIR_JVM_POR_MODULO_023.ps1

3. Compilar:

cd .\android
.\gradlew.bat --stop
cd ..
flutter clean
Remove-Item -Recurse -Force .\build -ErrorAction SilentlyContinue
Remove-Item -Recurse -Force .\.dart_tool -ErrorAction SilentlyContinue
Remove-Item -Recurse -Force .\android\.gradle -ErrorAction SilentlyContinue
flutter pub get
flutter build apk --debug -v *> build_023.log
