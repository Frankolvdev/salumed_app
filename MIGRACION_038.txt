MegaZIP 038 — Notificaciones con image/user nulos

Base exacta:
- salumed_app-main (14).zip

Error:
type 'Null' is not a subtype of type 'Map<String, dynamic>'
error en getNotifications

Causa:
NotificationModel.fromJson comprobaba únicamente si existían las claves
"image" y "user". Cuando el backend enviaba:

"image": null
o
"user": null

el modelo intentaba ejecutar AssetModel.fromJson(null) o UserModel.fromJson(null).

Corrección:
- NotificationModel.fromJson acepta datos dinámicos.
- Verifica que la notificación sea realmente un Map.
- Solo convierte image y user cuando son Map<String, dynamic>.
- Mantiene null cuando esos campos vienen vacíos.
- Normaliza campos de texto de forma segura.

No modifica:
- endpoint de notificaciones;
- login;
- initProcess;
- alertas;
- navegación;
- diseño;
- backend.

Archivo:
lib/models/notification.dart
