MegaZIP 01T — Font Awesome multilínea e IconData

Causa:
El parche 01S convirtió llamadas de una sola línea, pero quedaron llamadas
multilínea a Icon(FontAwesomeIcons...) y referencias pasadas a parámetros
IconData.

Cambios:
- 41 constructores Icon(...) multilínea se convierten a FaIcon(...).
- 11 referencias usadas como IconData reciben .data.
- Se conservan los mismos iconos, colores, tamaños, posiciones y acciones.
- No se modifican plugins, pagos, audio, fechas ni timelines.

Después de descomprimir:
flutter clean
Remove-Item -Recurse -Force .\.dart_tool -ErrorAction SilentlyContinue
flutter pub get
flutter run

Git:
git status
git add .
git commit -m "fix: complete Font Awesome 11 icon data migration"
git push
