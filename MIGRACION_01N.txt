MegaZIP 01N — Eliminar uni_links obsoleto y no utilizado

Problema:
uni_links 0.5.1 usa jcenter() y una configuración Android antigua incompatible
con AGP 9.

Análisis:
- No existen imports de package:uni_links en lib/.
- No se usan getInitialUri, uriLinkStream ni linkStream.
- Por tanto, el paquete está declarado pero no es usado por la aplicación.

Cambio:
- Se elimina únicamente uni_links del pubspec.yaml.
- No se toca AndroidManifest.xml.
- Los intent-filter/deep links declarados en Android permanecen intactos.
- No cambia diseño ni funcionalidad actual.

Después de descomprimir:
flutter clean
Remove-Item -Recurse -Force .\.dart_tool -ErrorAction SilentlyContinue
Remove-Item -Force .\pubspec.lock -ErrorAction SilentlyContinue
flutter pub get
flutter run

Git:
git status
git add .
git commit -m "fix: remove unused legacy uni links plugin"
git push
