MegaZIP 01Y — assets_audio_player local con Java 17

Error actual:
android/build.gradle.kts line 67:
sourceCompatibility has been finalized

Causa:
El parche 01X intentó modificar compileOptions de la app después de que AGP 9
ya había finalizado esa propiedad.

Solución:
- Elimina únicamente el bloque:
  BEGIN/END SALUMED ANDROID COMPILE OPTIONS 17
- Copia assets_audio_player 3.1.1 desde Pub Cache a:
  plugins/assets_audio_player
- Cambia directamente en el plugin local:
  sourceCompatibility JavaVersion.VERSION_17
  targetCompatibility JavaVersion.VERSION_17
- Añade dependency_override local.
- No toca código Dart ni comportamiento del audio.

Aplicación:
Set-ExecutionPolicy -Scope Process Bypass
.\INSTALAR_ASSETS_AUDIO_PLAYER_LOCAL_01Y.ps1

Después:
cd .\android
.\gradlew.bat --stop
cd ..
flutter clean
Remove-Item -Recurse -Force .\android\.gradle -ErrorAction SilentlyContinue
Remove-Item -Recurse -Force .\.dart_tool -ErrorAction SilentlyContinue
Remove-Item -Force .\pubspec.lock -ErrorAction SilentlyContinue
flutter pub get
flutter run

Git:
git status
git add .
git commit -m "fix: vendor assets audio player with Java 17"
git push

La carpeta plugins/assets_audio_player debe subirse a Git.
