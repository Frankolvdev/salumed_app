MegaZIP 01M — File Picker compatible con Flutter 3.44 / AGP 9

Problema:
file_picker 3.0.4 usa jcenter() y una configuración Android antigua que no
funciona con Android Gradle Plugin 9.

Solución:
- file_picker: 10.3.10
- Se conserva FilePicker.platform.pickFiles(), por lo que no hay que cambiar
  client_add_achive.dart ni la experiencia del selector de archivos.
- Se garantizan temporalmente:
    android.newDsl=false
    android.builtInKotlin=false
  para compatibilidad gradual con plugins heredados bajo AGP 9.

No se editan archivos dentro de Pub\Cache.

Después de descomprimir en la raíz:
flutter clean
Remove-Item -Recurse -Force .\.dart_tool -ErrorAction SilentlyContinue
Remove-Item -Force .\pubspec.lock -ErrorAction SilentlyContinue
flutter pub get
flutter pub deps | Select-String "file_picker"
flutter run

La dependencia resuelta debe mostrar file_picker 10.3.10.

Git:
git status
git add .
git commit -m "fix: update file picker for AGP 9 compatibility"
git push
