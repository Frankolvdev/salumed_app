MegaZIP 029 — JVM automática con configuración diferida segura

Base exacta:
- salumed_app-main (8).zip

Error actual:
Cannot run Project.afterEvaluate(Action) when the project is already evaluated.

Corrección:
- Se elimina la llamada tardía que causaba el error.
- Se usa tasks.withType(...).configureEach.
- Cada tarea Kotlin busca la tarea Java equivalente por nombre.
- Kotlin adopta el mismo target real de Java:
  1.8, 11, 17 o 21.

No modifica:
- código Dart
- código fuente de plugins externos
- Pub Cache
- diseño
- pagos
- applicationId
- compileSdk
- targetSdk

1. Descomprimir encima de:
   F:\SALUMED\CODE\APP

cd .\android
.\gradlew.bat --stop

Remove-Item -Recurse -Force .\.dart_tool -ErrorAction SilentlyContinue
