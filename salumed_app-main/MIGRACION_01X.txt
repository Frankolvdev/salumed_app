MegaZIP 01X — Java 17 real para assets_audio_player

El parche 01W sí cambió Kotlin a JVM 17, pero assets_audio_player conserva:

compileDebugJavaWithJavac = 1.8
compileDebugKotlin = 17

La causa es que el plugin define Java 1.8 dentro de android.compileOptions.

Este parche configura directamente la extensión Android legacy de AGP 9:

compileOptions {
    sourceCompatibility = JavaVersion.VERSION_17
    targetCompatibility = JavaVersion.VERSION_17
}

Se aplica a:
- com.android.library
- com.android.application

No modifica Dart, audio, diseño ni funcionalidad.

Aplicación:
1. Descomprimir en F:\SALUMED\CODE\APP
2. Ejecutar:

   Set-ExecutionPolicy -Scope Process Bypass
   .\CORREGIR_ANDROID_COMPILE_OPTIONS_17_01X.ps1

3. Limpiar:

   cd .\android
   .\gradlew.bat --stop
   cd ..
   flutter clean
   Remove-Item -Recurse -Force .\android\.gradle -ErrorAction SilentlyContinue
   Remove-Item -Recurse -Force .\.dart_tool -ErrorAction SilentlyContinue
   flutter pub get
   flutter run
