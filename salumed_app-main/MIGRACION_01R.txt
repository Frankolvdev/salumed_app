MegaZIP 01R — assets_audio_player_web registrado solo para Web

Problema confirmado:
- El override local sí funciona.
- Flutter encuentra el paquete en plugins/assets_audio_player_web.
- Sin embargo, su pubspec todavía declara una plataforma Android.
- Flutter intenta inspeccionarlo como módulo Android y falla con:
  getLegacyAndroidExtension / NullPointerException.

Corrección:
- Se elimina únicamente la entrada Android del pubspec del plugin local.
- Se elimina plugins/assets_audio_player_web/android.
- No se toca lib/, web/, macOS ni el código Dart del plugin.
- Android sigue usando assets_audio_player 3.1.1.
- Web sigue usando assets_audio_player_web 3.1.1 desde la copia local.

Aplicación:
1. Descomprimir en F:\SALUMED\CODE\APP
2. Ejecutar:

   Set-ExecutionPolicy -Scope Process Bypass
   .\CORREGIR_PLUGIN_AUDIO_WEB_SOLO_WEB.ps1

3. Limpiar y recompilar:

   cd .\android
   .\gradlew.bat --stop
   cd ..
   flutter clean
   Remove-Item -Recurse -Force .\.dart_tool -ErrorAction SilentlyContinue
   Remove-Item -Recurse -Force .\android\.gradle -ErrorAction SilentlyContinue
   Remove-Item -Force .\pubspec.lock -ErrorAction SilentlyContinue
   flutter pub get
   flutter run
