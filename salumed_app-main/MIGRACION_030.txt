MegaZIP 030 — Referencia correcta a la tarea Kotlin

Error corregido:
android/build.gradle.kts:
- Unresolved reference compilerOptions
- Unresolved reference jvmTarget

Causa:
Dentro del configureEach de JavaCompile, this@configureEach apuntaba a la tarea
Java y no a KotlinCompile.

Corrección:
Se guarda primero:

val kotlinTask = this

y después se configura:

kotlinTask.compilerOptions {
    jvmTarget.set(kotlinTarget)
}

El script modifica el repositorio actual directamente. No reemplaza el archivo
Gradle con una copia anterior.

Aplicación:
1. Descomprimir en F:\SALUMED\CODE\APP
2. Ejecutar:

Set-ExecutionPolicy -Scope Process Bypass
.\CORREGIR_REFERENCIA_KOTLIN_TASK_030.ps1

3. Limpiar y compilar:

cd .\android
.\gradlew.bat --stop
cd ..

flutter clean
Remove-Item -Recurse -Force .\build -ErrorAction SilentlyContinue
Remove-Item -Recurse -Force .\.dart_tool -ErrorAction SilentlyContinue
Remove-Item -Recurse -Force .\android\.gradle -ErrorAction SilentlyContinue

flutter pub get
flutter build apk --debug -v *> build_030.log

Git:
git status
git add .
git commit -m "fix: configure Kotlin JVM target on the correct task"
