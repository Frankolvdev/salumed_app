MegaZIP 01V — Corrección del script Font Awesome

Problema:
PowerShell Get-Content -Raw devuelve $null cuando encuentra un archivo Dart vacío.
Regex.Matches no acepta un valor nulo.

Corrección:
- El script ignora archivos Dart vacíos.
- Convierte Icon(FontAwesomeIcons...) a FaIcon(...).
- Añade .data cuando FontAwesomeIcons se usa como IconData.
- Verifica todo lib/ al terminar.
- No reemplaza archivos con copias antiguas.

Aplicación:
1. Descomprimir en F:\SALUMED\CODE\APP
2. Ejecutar:

   Set-ExecutionPolicy -Scope Process Bypass
   .\CORREGIR_FONTAWESOME_REPO_ACTUAL_01V.ps1

3. Después:

   flutter clean
   Remove-Item -Recurse -Force .\.dart_tool -ErrorAction SilentlyContinue
   flutter pub get
   flutter run

git status
git add .
